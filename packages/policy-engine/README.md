# @agent-contract-lab/policy-engine

Deterministic parser and evaluator for Agent Contract Lab YAML contracts.

```sh
npm install @agent-contract-lab/policy-engine
```

Evaluate retained evidence against explicit command, path, and evidence
assertions. The engine separates deterministic verdicts from collection:
missing pre-action interception or absent facts remain `unknown`, not a
guessed pass or prevention claim.

See the [policy and contract specification](https://github.com/ManoharEldhandi/agent-contract-lab/blob/main/docs/policy-and-contract-spec.md).
